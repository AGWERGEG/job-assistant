## 安装

需要 Python 3.10+、Edge 或 Chrome。完整文档能力需要安装 requirements.txt；Codex 或兼容 API 二选一。纯 API 模式无需安装 Codex。

macOS / Linux：
```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python launch.py
```

Windows：
```bat
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe launch.py
```

安装好后，macOS / Windows 可双击“启动求职搭子”脚本；两端优先使用项目 .venv。终端窗口需保持开启。启动时会显示实际 Python 路径和缺失文档依赖。

## 首次使用

使用第三方扩展前，请核对招聘平台当前协议；平台可能限制插件接入，本项目没有取得平台授权或保证账号不受限制。[BOSS直聘协议入口](https://about.zhipin.com/agreement)。

1. 在 edge://extensions 或 chrome://extensions 打开开发者模式，加载本项目 extension 文件夹。
2. 打开扩展侧栏，点击“连接我的工作台”；工作台会显示一次本机确认，不需要复制配对码。手动配对仅在“高级诊断与手动连接”中使用。
3. 在工作台选择接入：本机 Codex（先自行登录 CLI），或 Chat Completions 兼容 API（填写地址、模型、密钥）。
4. 选搭子后，可上传/填写简历；也可在配对侧栏打开 BOSS 或智联本人在线简历页，点击“读取在线简历并核对”。智联入口已在当前 macOS Edge 页面验证能生成本地草稿；不同账户或新版页面仍需核对。页面内容只在明确点击后进入草稿，核对加入编辑器后仍需手动保存与确认脱敏。
5. 回招聘网站打开岗位，确认目标后聊天。简历等后台结果从“任务与成果”进入工作台核对。公司资料只保存当前已加载栏目和卡片，不自动翻页。若导入选择不唯一或公司材料为空，界面会提示并停止保存。
6. 保存简历版本后，本机回填姓名和联系方式；确认后导出 DOCX / PDF / TXT。

Codex 模式使用独立 CLI，默认不固定模型名称，跟随当前 CLI 内置默认模型；不会加载个人工具配置。接入检查只验证登录凭据存在，模型权限、网络和额度仍需实际任务验证。API 连接测试只发固定测试文字，可能消耗少量服务商额度。

## 日常使用与升级

请用启动脚本或 launch.py 自动打开已授权的工作台。单独输入本机地址只能打开页面外壳，不能取得个人资料或连接令牌。

默认从 http://127.0.0.1:8421 启动；若端口已占用，启动器会自动尝试 8422—8430，并在终端显示实际地址。新版侧栏会在这些端口中优先寻找同版服务。默认个人资料目录是当前解压目录的 data/；演示使用 data-demo/，它同样可能已含你上传的真实资料。需要沿用旧资料时，先停止正在使用该数据目录的旧工作台，再明确指定旧目录；启动器不会同时运行两个版本写同一份资料。

升级前等待任务结束，停止旧服务，并备份原数据目录。把新版本解压到独立目录，用新版本显式继续原目录：
```bash
./runtime/bin/python3 launch.py --data-dir "/你的原数据目录" --port 8421
```
Windows 将解释器替换为 .venv\Scripts\python.exe。不要用空 data/ 覆盖旧目录。更新扩展加载路径/重载扩展、刷新网页，再重新配对。当前包不附带个人数据或密钥。

工作台改过岗位后，侧栏出现“同步已保存岗位”时点击同步；该动作读取工作台修改，不重新抓网页覆盖它。
取消 API 请求会停止本机请求进程并释放通道；远端是否已停止推理或计费由服务商决定。

## 支持范围与已知限制

- 招聘网站页面结构会变化。BOSS 独立详情页仍有历史识别失败场景；智联已完成当前双栏页实站读取，58 的当前结构已有自动化覆盖但登录后的最终实站复测尚未完成。识别失败时可用侧栏“岗位读取帮助”或工作台手动补充 JD。
- 在线简历导入只在明确点击后读取当前页面可见栏目，不读取附件、头像、平台诊断、隐私设置或 Cookie。BOSS 流程有旧版回归；RC4.3.4 的智联流程通过了合成 DOM 回归，并在当前 macOS Edge 页面完成“点击读取→本地草稿核对入口”验收。尚未把草稿加入正式档案或验证其他账号版式。平台掩码的手机号/邮箱无法还原；空栏目与未读到栏目会分别显示。
- 智联公司招聘页只读取当前已加载的同公司岗位卡片：标题、链接、薪资和可见条件；不自动翻页，也不把“精选职位推荐”算作公司岗位。卡片不是完整 JD；需要完整对照时，打开具体岗位详情后再明确保存为同公司对照材料。RC4.3.5 已在当前 Edge 页面验证读取数量，真实用户数据中的保存与后续分析仍待验收。
- PDF 仅支持可提取文本的文件，最多 30 页；扫描件需先转文字，未内置 OCR。
- PDF 导出需要可嵌入中文字体。默认检查常见系统字体；失败时设置 JOB_ASSISTANT_CJK_FONT 或先导出 Word。
- 脱敏采用本地规则和用户核对，不保证自由文本完全匿名。原件与 API 密钥存于本机；本机数据库不是加密保险箱。
- 对话上下文有长度范围；生成内容是建议，不是事实，简历和面试内容需自行核对。
- 普通聊天与长任务分通道；网络异常可能导致失败，任务记录会保留。重启后运行中任务依原租约恢复，最迟需等待原 15 分钟租约到期。
- 此 macOS 包使用 Apple Silicon Python 3.12，未提供 Intel Mac 包；未进行代码签名、公证或扩展商店发布。Windows 包的说明见其独立测试文档。
