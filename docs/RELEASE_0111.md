# v0.11.1 · 统一视觉层

本版完成侧栏和工作台的最后一轮视觉统一，保留 v0.11.0 的对话优先布局，不改后端、数据结构、任务协议或配对语义。

## 视觉系统

- 新增 `extension/theme.css`，由侧栏直接加载、工作台通过本地 `/theme.css` 加载。
- 主色为松绿色 `#315e4b`，背景为暖灰白，正文为深灰绿，辅助色为浅松绿。
- 主动作使用深绿色，次级动作使用浅松绿，错误使用浅红，待处理/需要确认使用浅米黄。
- 统一按钮、输入框、下拉框、对话框、折叠项的圆角、边框、焦点轮廓和禁用状态。
- 统一“伴”字标识、消息气泡、消息间距、辅助文字和状态提示。
- 支持 `prefers-reduced-motion: reduce`，没有增加依赖和动效负担。

## 侧栏表现

- 顶部品牌和连接状态使用同一套标识。
- 对话气泡、快捷按钮和输入区使用统一的柔和层级。
- 岗位切换提示采用待确认米黄色；错误状态使用红色边线和浅红底。
- 详情弹层、配对界面和首次引导继续沿用已有折叠和隐藏逻辑。

## 工作台表现

- 顶部标识、导航、按钮和聊天区使用与侧栏一致的主题变量。
- 聊天主区域保持白色表面，消息区、输入区和快捷动作使用低对比度分隔。
- 任务卡、公司资料、机会列表和简历结果统一边框与展开状态。
- 首次引导保持单步骤聚焦布局，不被统一主题覆盖。

## 验证

- Python：80 项通过。
- 工作台与扩展 JavaScript：51 项通过。
- 真实隔离浏览器视觉验收：
  - 380×720 侧栏：发送按钮仍在首屏，主题色已加载。
  - 320×560 侧栏：无水平溢出，详情弹层可展开/收起。
  - 1280×720 工作台：聊天首屏、任务面板和简历结果页主题一致。
  - 768×600 工作台：输入区保持可见，无脚本错误。

## 更新方式

重新加载 `extension` 目录并刷新工作台/BOSS。服务重启后需按原流程重新配对；不会修改本地档案、岗位、对话或任务。

本版完成基础视觉系统。后续如果继续优化，建议只做品牌图形、图标和少量动效，不再同时改动信息架构。
