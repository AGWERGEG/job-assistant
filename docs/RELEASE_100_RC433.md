# v1.0 RC4.3.3 智联兼容源码测试包

日期：2026-09-23。此版本是开发测试用源码包，不是正式版，也不是 macOS/Windows 便携运行包。macOS 便携包仍为 RC4.3.2。

## 本版改动

- 在线简历经历合并只自动去掉规范化后完全相同的文本；相似但不同的经历保留给用户核对。
- 增加智联在线简历的显式点击导入入口、来源 schema 与 HTTPS 页面校验，并沿用本地草稿、工作台核对和手动保存流程。普通页面轮询与诊断不读取简历正文。
- 增加智联公司 `.seo-card` 介绍读取与当前已加载招聘卡片采集；空材料不进入保存流程，保存错误显示在公司资料弹窗内。
- 延续智联独立岗位详情页由用户选择文字补充 JD 的兜底流程。

## 验证状态

- 本次没有运行 Python 或 Node 自动化回归。
- 本次没有在 Edge 验收智联简历导入、公司资料保存或招聘卡片读取。
- 仅执行源码发布包白名单封装，并检查 ZIP 完整性及禁止文件/用户数据排除情况。
- 智联岗位读取此前已有真实 Edge 证据；58 登录后的最终实站复测仍未完成。这些旧证据不等同于本版功能验收。

## 使用与数据边界

请解压到独立的新目录，在 Edge 加载其中的 `extension/`，并使用隔离的测试档案。不要覆盖现有安装目录或用户数据目录。包不含 `data/`、`data-demo/`、SQLite 数据库、API 密钥或本机浏览器配置。读取在线简历必须由用户明确点击，产生的内容先进入本机草稿供用户核对。
