# RC4.3.27 · 专项成果引用与聊天展开测试版

本版在RC4.3.22基础上增加专项成果承接：

- 工作台聊天页显示当前岗位已完成的深度分析、岗位简历、面试、HR沟通成果目录；卡片默认折叠，可展开安全查看结果正文。
- 卡片提供“围绕此结果继续聊”，引用固定任务ID发送；后端校验成果属于当前岗位、已完成且类型允许，不能由客户端伪造正文或跨岗位引用。
- 输入框输入 `/` 弹出 `/简历`、`/深入分析`、`/面试`、`/HR沟通`，选择后只填入前缀并绑定当前岗位最近对应成果，不自动发送或创建任务。
- 对话 Agent 收到明确引用时将该成果作为本轮焦点；没有引用时只看到有限成果目录，遇到“这个/继续”无法唯一对应时应要求用户选择。
- 普通聊天、快捷后台任务、JD/HR绑定核心保持原流程。

验证：Python完整回归162项通过，Node现有测试124项通过，Python编译及Node语法检查通过。新增成果目录使用虚构临时SQLite基础检查；真实Edge/DeepSeek本版专项引用连续对话尚未重新实测。仍是RC测试版。


本版另修复工作台静态脚本缓存：workspace.js、reply-format.js、app.js均带版本参数，升级后不会继续使用旧前端。侧栏同步刷新命令与成果引用入口。


本版修复工作台缺失 command-menu 节点、任务卡旧按钮文案，以及引用结果发送未纳入幂等身份的问题。


本版补充后续分析授权：用户根据新增经历重新分析、再次分析或再生成分析报告时，会进入后台任务授权路径。


本版修复/命令菜单缺失节点、空白菜单项、专项任务按钮改为“展开”，并保证菜单选择携带真实引用任务ID。
