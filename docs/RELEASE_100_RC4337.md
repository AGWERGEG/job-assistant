# RC4.3.37 · 企业资料上下文与 BOSS 跳转修复测试版

本版针对 RC4.3.36 Edge 现场复现的两个问题修复。

- 已保存公司资料页显示有来源材料，但普通聊天仍回答“企业公开资料研究是空的”。根因是 `DialogueSession.snapshot()` 只传岗位和任务资料，没有传岗位绑定的公司 dossier。现在普通聊天也会读取当前岗位绑定的已保存公司材料，并遵守来源、岗位和脱敏边界。
- 首次引导“回到 BOSS 继续”只更新提示文本，没有真正导航。现在按钮会打开 BOSS 招聘页，侧栏继续承担岗位读取与目标确认。

## 验收

- 真实 Edge 现场确认当前岗位“有赞”已有 3 条公司材料；原逻辑在聊天中仍声称企业资料为空。
- 临时数据库回归确认：已保存公司介绍进入普通聊天快照，`company_background.evidence` 可见；未读取真实 `data/`。
- BOSS 跳转逻辑改为打开 `https://www.zhipin.com/web/geek/job-recommend/`。
- Python 和 Node 回归沿用 RC4.3.36 全量检查。

## 限制

本版仍是 v1 RC 测试版，不是正式 v1。企业公开网络研究仍需用户明确触发和来源确认；不会自动登录、读取 Cookie 或持续监控企业信息。
