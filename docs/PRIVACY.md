# 求职搭子：资料与发送范围

这是本机运行的求职辅助候选版。档案、上传原件、岗位、对话、确认经历与成果保存在你选择的本机资料目录。生成、复制和打开页面都不代表发送 HR、投递或真实求职进展。

模型接入由你选择。本机 Codex 模式使用你的 Codex 登录与服务；兼容 API 模式将经过本机脱敏的必要材料发送到你配置的服务商地址。服务商的保存、计费和隐私政策由其制定。填写第三方 API 地址前请核对服务商身份。

经历必须经你核对保存才成为长期事实；修改事实后需重新批准脱敏。自由文本规则不能保证完全匿名，请查看发送预览，补充需要隐去的姓名、地址和其他私密词。历史 AI 建议不是事实证据。导出简历的个人信息回填只在本机核对，不作为模型材料。

公开公司研究只发送当前公司名和有限公开主题。免密搜索访问 Bing；选择 Tavily 时，公司查询与所需搜索密钥会发给 Tavily。公开网页与搜索摘要会显示来源，需核对身份和时效，不能当作核实后的企业事实。

侧栏只在明确操作后保存当前页面材料，不读取 Cookie、不自动翻页、不代发或投递。批准本项目侧栏连接后，它能读取已保存岗位、与目标关联的用户原话和建议，并按你的明确请求发起任务；不能读取模型密钥、原始简历附件或任意本机文件。更新固定身份的扩展源码需要重载并重新配对。

本机目录与数据库不是加密保险箱。API 密钥目前保存在本机数据库中；资料副本不导出密钥。拥有你系统账户权限的程序仍可能访问这些本机文件；不要公开上传资料目录。先下载并核对本机副本，再决定是否删除；删除需要任务静止及明确确认。

取消会停止本机请求与迟到写回；远端是否停止推理和计费由服务商决定。当前未进行签名、公证、完整平台或真实资料迁移验收，仍不是正式 v1。
