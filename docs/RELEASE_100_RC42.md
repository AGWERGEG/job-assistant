# v1.0 RC4.2 · 模型成本与长任务状态优化

本轮只改变每次模型调用所使用的脱敏任务材料，不删减或覆盖本机 SQLite 中的完整档案、岗位、公司证据和历史结果。

## 输入预算

- 新增 `app/prompt_budget.py`，按任务类型建立字段白名单与字符预算。
- 在本机根据岗位标题、JD 和本轮问题，为个人档案、确认事实与公司材料选择相关片段；不使用额外模型、向量库或网络请求。
- 日常聊天、快速判断、HR 招呼和专业任务使用不同预算。没有公司资料时不再发送公司规则；没有逐条事实时不发送事实引用说明。
- 历史结果只保留延续策略所需字段。简历任务只有在存在同类旧稿时才携带受限的旧稿片段。
- 发送材料会明确说明“未发送不代表没有相关经历”，防止模型把本地筛选误判为候选人经历缺失。

用本机现有失败任务的同一脱敏快照离线测量，提示由 6175 字降至 4862 字，减少 21.3%。这是单一样本，不代表所有简历的固定比例；更长且分段清晰的档案通常会有更大收益。

## 成本与连接反馈

- 任务继续记录输入字符数；兼容 API 返回 `usage` 时，额外记录输入、输出与总 Token，并显示在工作台。
- “测试连接”在固定短句之外，增加一个不含用户资料的极小 JSON 测试，用于区分短对话可用与专业结构化任务可用。
- 不在专业任务失败后自动二次调用模型，避免一次失败产生双倍费用。

## 重试与等待

- 重试后从本次重新排队/领取时间计时，不再沿用任务第一次创建时间。
- 侧栏与工作台显示“第 N 次尝试”和“本次已等待”，避免把重试间隔误报成连续模型调用。
- 超过 90 秒提示为“模型长请求响应较慢”，任务失败后正常显示归一化错误及重试入口。

## 验证边界

- Python 全量测试覆盖档案不变、相关片段选择、API usage 回传、连接结构化测试与任务状态。
- 浏览器合成测试覆盖侧栏和工作台的本次计时与重试次数。
- 没有调用真实用户配置的模型进行付费测试；真实 Token 数只在服务商实际返回 `usage` 时展示。
