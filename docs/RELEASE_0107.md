# v0.10.7 · 配对状态与岗位引导冲突修复

修复侧栏在服务重启、令牌失效或页面状态变化后同时显示“连接我的工作台”和“就看这个岗位”的问题。

侧栏现在按以下优先级处理：

1. 没有有效 Bridge 令牌：只显示配对区域，隐藏岗位、公司背景、快捷键和聊天入口。
2. 已配对但当前页面变化：保留配对和已保存岗位，只提示页面尚未关联，不重新要求配对。
3. 已配对且读到岗位：显示当前岗位引导或正常快捷功能。

异常处理只会在服务端明确返回“未配对、服务已重启、401”等鉴权错误时切换到配对状态；“页面已变化”“岗位未关联”“正文还在读取”等内容不会触发配对表单。

同时，连接按钮失败时会保持未配对状态并保留配对表单；成功后立即刷新侧栏引导。普通断开会清除当前浏览器会话授权，服务端同步撤销该 Origin 的令牌。

## 验证

- Python 后端：80 项通过。
- 工作台与扩展 JavaScript：48 项通过。
- 覆盖未配对侧栏、配对后首次引导、模型检查失败重试、重连、结束引导和普通页面变化不触发重新配对。

更新扩展后请在 `edge://extensions` 点击“重新加载”，再刷新 BOSS 页面。若服务已重启，侧栏只需重新配对一次；不会删除本地岗位、对话或简历资料。
