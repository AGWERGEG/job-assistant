# v0.11.2 · 引导出口与 Codex 鉴权检查

- 工作台引导增加“上一步”“跳过引导，进入工作台”“检查 / 更换模型接入”。首个配对步骤的上一步禁用。
- guide_view 持久化回看位置；回退不删除简历、角色、脱敏确认、岗位或任务，刷新后仍在所选步骤。
- 跳过后退出聚焦布局、恢复导航并打开设置，清除本页强制配对导航状态；设置可重新打开引导。跳过不等于完成脱敏审核，不会使未确认资料可以发给模型。
- 回看已确认脱敏档案时可沿用审核；修改资料依旧触发原审核指纹规则。
- 首次任务失败后，下一次明确发起的任务可以成为新的引导任务，避免始终指向失败任务。
- Codex 连接测试从“检查文件存在”改为检查同一 CLI 的 login status。退出码 0 仅代表存在凭据，不保证凭据未过期、网络、模型权限与额度。
- Codex 模型侧 401 优先于连接中断分类；插件列表的独立 401 不直接等同模型鉴权失败。检查输出不保存、不回显原始凭据或日志。

## 本机诊断

2026-09-18：独立 CLI 0.155.0-alpha.2.6 的 login status 返回 Not logged in、退出码 1。固定 ping 最小调用在 WebSocket 连接重置后回退 HTTPS，模型端点返回 401 Missing bearer or basic authentication in header。不是浏览器侧栏配对失败；工作台 Codex worker 使用独立 CLI，不等同当前桌面聊天会话已授权。

恢复方法：在终端执行 codex login 完成本人登录，再运行 codex login status，回工作台测试连接并重试失败任务。本轮仅诊断，没有修改登录凭据；登录后仍需实际模型请求验证。

官方参考：https://learn.chatgpt.com/docs/developer-commands#codex-login
