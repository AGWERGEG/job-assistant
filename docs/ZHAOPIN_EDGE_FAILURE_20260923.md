## RC4.3.2 现场证据与当时结论（历史）

1. Edge 扩展管理页显示实际加载的是 `.../outputs/job-assistant 4/extension`，扩展 ID `ndcmmcibkpcmimmdhjebaiicnilmckak`、版本 `1.0.0-rc.4.3.2`。运行中工作台进程的当前目录也是 `job-assistant 4`。该副本和源码及此前测试 ZIP 的关键扩展/后端文件逐字节一致。因此本次故障不能归因于旧扩展或后端副本。
2. Edge 当前智联公司详情页可见“公司介绍”正文；侧栏显示公司身份，但显示 `0 个栏目 / 0 张已加载岗位卡片`。侧栏诊断状态为 `company`。DevTools 中实际结构为 `.seo-card > .seo-card__header > h2.seo-card__title` 与同一 `.seo-card` 下的 `.seo-card__content > .introduction__text`。`extension/extractor.js:413` 只从标题 `h2` 的直接后续兄弟节点找正文，现有备用选择器也不包含这层结构，所以漏读。用同样层级的虚构 DOM 复现：`status=company`、公司键有效，但 `sections=0, jobs=0, categories=0`。
3. `extension/extractor.js:264,307,454` 只把 BOSS `/web/geek/resume` 识别为可读取的在线简历。智联 `https://i.zhaopin.com/resume` 仅有无正文结构诊断，普通快照仍返回 `unavailable`。`extension/panel.js:136,188` 因此隐藏简历入口，点击处理和 URL 校验也只接受 BOSS。`app/profile_import.py:11,38,127` 的协议、来源校验和草稿来源同样只支持 BOSS。智联简历读取失败是整条能力链尚未实现，现有测试 `tests/test_site_adapters.cjs` 也明确断言智联简历状态为 `unavailable`。
4. 已绑定的目标公司只要身份相同，`extension/panel.js:43` 就允许“补充这家公司的背景”按钮，即使栏目、卡片和分类全为空。点击后后端 `app/company.py:163` 会拒绝空材料。侧栏错误写入主界面的 `#status`，而按钮位于 `#details-dialog` 内，弹窗打开时用户可能看不到报错，因此呈现“未响应”。这是代码路径判断；本轮未在真实资料上点击保存，未观察该次请求的实际响应。
5. `extension/extractor.js:437` 的招聘卡片读取被 `source_site==='boss'` 条件包住；智联公司招聘页即使加载卡片也不会进入当前采集分支。现有智联公司测试采用 `<h2>` 与正文直接相邻的虚构结构，覆盖不到真实 `.seo-card` 布局。

当前公开公司页还带有“本介绍由 DeepSeek AI 智能生成，仅供参考”的说明。若采集该段，来源应标为平台生成/待核对，不能沿用通用“企业自述”标签。

## 已完成的代码改动（尚未验证）

- `extension/extractor.js` 为智联 `.seo-card` 按卡片读取公司介绍/业务，标记 AI 生成说明，并在同公司招聘页尝试读取当前已加载的职位卡片。

- `app/profile_import.py` 为智联新增独立来源协议和 URL 校验，保留旧 BOSS schema 与草稿格式；工作台显示真实来源。
- Bridge status 增加智联简历能力标记；平台生成公司介绍在本机证据中保留来源标签。

本轮没有增加或运行测试，也没有重新加载 Edge 扩展、调用真实简历导入或保存公司材料。以上是代码状态，不是通过验收的结论。

## 9. RC4.3.4 智联简历故障根因与修复结果

- RC4.3.3 实际加载扩展在 `i.zhaopin.com/resume` 点击读取时报“栏目未能唯一定位或尚未加载完成”。只读取 DOM 标签、类名和节点数量的现场检查显示：正文栏目标题的祖先类含 `diagnosis-scroll`，被通用 `resumeExcluded` 的 `[class*="diagnosis"]` 误排除；右侧栏目导航类为 `jobs-bar`，未被排除，反而成为候选标题。重复标签导致部分栏目数量为 2、唯一定位失败。
- RC4.3.4 仅在智联分支采用专用排除规则，允许正文 `diagnosis-scroll`，排除 `jobs-bar` 与真实诊断/附件/隐私区域。进一步按页面条目容器拆分求职意向和工作经历，滤除“添加”“查看全部”等界面动作。BOSS 简历规则保持不变。
- 自动回归：Python 106 项、Node 90 项通过。真实 macOS Edge 中把同版提取脚本加载进当时的测试扩展，重载/刷新并重新连接工作台后，明确点击读取成功创建本地草稿；界面显示个人优势 1、求职意向 3、工作经历 2、教育经历 2，空栏目没有误填。没有点击“加入编辑器”、保存档案或调用模型。
- 现场服务及加载扩展的版本标识仍为 RC4.3.3；完整新解压 RC4.3.4 包尚未单独启动。其他智联页面版式、公司资料保存→分析引用、58 登录后实站路径仍未验证。不要把本次简历草稿生成写成这些路径通过。
