# RC4.3.35 · UI 与设置页整合修复测试版

本版针对 RC4.3.34 的整体 UI 不协调和设置页混杂问题完成整合。

## 调整内容

- 工作台和侧栏统一结果正文读取顺序：主结果、Markdown 依据、摘要逐级回退；补充结果卡、详细依据、引用标签和按钮层级。
- 任务与成果名称继续使用中文类型、序号和弱化日期；面试复盘与面试准备分开命名。
- `/` 继续只引用已有专项成果；引用标签压缩为“引用：分析 2”，摘要作为辅助信息，不重复挤占输入区。
- 设置页增加档案、默认模型、浏览器侧栏三张状态卡，并分成个人与搭子、默认模型、独立连接、任务模型分工、浏览器侧栏五个区域。
- 独立连接显示使用任务；任务模型分工显示已生效连接和模型；保存前显示变更预览；移除连接必须先确认并列出受影响任务。
- 默认模型区分未配置、已保存待测试和本次测试通过，连接失败会回退到待测试状态。

## 验证

- Python 完整回归：198 项通过。
- Node 工作台与扩展回归：135 项通过。
- `node --check web/app.js`、`node --check extension/panel.js` 和 manifest JSON 检查通过。
- 本版没有修改任务路由、脱敏边界或数据库结构，没有读取 `data/`、`data-demo/`。

## 限制

本版仍是 v1 RC 测试版，不是正式 v1。真实招聘网站 DOM 和用户当前 Edge 页面尚未进行现场联动验收；Node 测试使用隔离 jsdom。
