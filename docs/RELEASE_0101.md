# v0.10.1 就地确认进展与结果提醒

2026-09-17。继续v0.10交互优化，本轮仅变更工作台与本机后端，侧栏保持0.10.0，不新增扩展写入权限或模型调用。

## 使用

- HR招呼结果旁：我已发出这条招呼 / 收到面试邀请了。
- 已验收简历版本旁：我已投递这版简历。未验收草稿没有此入口。
- 机会标题下：我收到面试邀请了；面试准备/复盘结果旁也可确认实际面试进展。
- 所有快捷操作先打开确认窗口，显示来源绑定岗位，复选框默认未选。确认后仅写入本机记录，不发送/投递/预约。取消不写入。
- 邀请记录成功后抵达该岗位面试区，不自动生成面试卡、不调用模型。误记可在该机会记录页撤销。
- 首页后台任务分处理中、需要处理、待查看，已查看默认隐藏，可展开。完成结果有“我已查看这份结果”按钮，可撤回为待查看；不以打开页面/滚动判定已读，更不等同简历验收。
- 旧任务升级后默认待查看，未替用户批量标已读。状态本机持久保存。

## 一致性边界

快捷动作绑定创建确认窗时的岗位和来源，不使用之后变化的selected。后端核对来源类型、来源所属岗位、任务完成状态及允许动作，拒绝跨岗或伪造动作。

同一来源+动作只快捷记一次（事务+确定性ID），防双击、重试和刷新重复计数；撤销后可以重记。不同来源可能对应同一次真实动作，本轮没有语义去重，用户需核对并撤销重复记录。其他次真实进展仍可在完整记录页手动新增。

已查看绑定任务完成版本updated，旧结果状态不能覆盖新结果。模型结果、已读状态与实际进展彼此独立；复制/下载/查看都不自动算发送。
