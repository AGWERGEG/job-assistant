# 智联在线简历修复源码测试包 · v1.0 RC4.3.4

这是供 Edge 测试的源码与扩展 ZIP，不是正式版或便携安装包。修复范围和验证证据见 [RELEASE_100_RC434.md](RELEASE_100_RC434.md)。

请解压到新的独立目录，启动其中的工作台，并在 Edge 加载其中的 `extension/`。若原来加载 RC4.3.3，先停用旧副本，刷新智联简历页后再连接侧栏。点击读取只会创建本机草稿；核对后仍需由用户决定是否加入编辑器和保存档案。

当前 macOS Edge 页面已验证草稿中有 3 个求职意向和 2 段工作经历，项目/证书等空栏目未被误当成内容。其他智联版式和企业资料链路仍待验收。ZIP 白名单不包含 `data/`、`data-demo/`、SQLite、密钥、浏览器配置或依赖缓存。
