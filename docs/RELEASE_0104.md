# v0.10.4 API 鉴权提示修复

2026-09-18。修复兼容 API 首次配置时的排查歧义。

- “测试连接”只读取本机已保存的配置。若 API 密钥尚未保存，会在本机直接提示“先保存接入方式”，不会发送无鉴权请求到服务商。
- 服务商返回 HTTP 401 时，错误提示明确区分为鉴权未通过：先确认页面显示“已保存密钥”，随后在服务商控制台核对密钥有效性与可用状态。
- 仍不显示、不写入任务或保存服务商的错误正文；密钥不会回显给工作台、侧栏或模型提示词。
- 修复 v0.10.3 的旧用户兼容：历史已建档用户即使曾保存过接入设置、留下不完整引导字段，也会被识别为已完成引导，不再被强制带回角色选择页。只有新引导或用户主动点击“重新查看首次引导”才会写入引导版本标记。

DeepSeek 官方 Chat Completions 文档目前支持 `https://api.deepseek.com`（或兼容的 `/v1` 前缀）与 `deepseek-v4-pro`；因此本次截图中的地址和模型名不是首要疑点。详见 [DeepSeek 官方 API 文档](https://api-docs.deepseek.com/)。
