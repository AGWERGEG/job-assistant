# 智联兼容源码测试包 · v1.0 RC4.3.3 · 2026-09-23

这是源码与扩展开发测试包，不是正式版。智联简历和企业资料代码刚完成初版修改，未运行自动化回归，也未完成真实 Edge 验收；请在独立空目录安装和测试。

## 本包包含

- 简历经历文本仅在规范化后完全相同时自动去重；相似但不同的经历保留给用户核对。
- 智联公司页/招聘页身份校验、窄来源 URL 校验和公司资料侧栏流程的代码调整。
- 智联独立岗位详情页的手动 JD 选中文字兜底。
- 智联在线简历只在用户明确点击后读取当前可见栏目，走独立 schema、本地草稿和工作台核对流程；普通轮询/诊断仍不读取简历正文。
- 智联公司详情页按 `.seo-card` 读取介绍，智联公司招聘页尝试读取当前已加载的职位卡片；空材料不会触发保存。
- 自动化测试、实施方案和当前交接记录。

## 安全边界

- ZIP 不包含 `data/`、`data-demo/`、SQLite 数据库、API 密钥或本机浏览器配置。
- 安装后首次运行会在应用目录创建数据目录。请把测试放在独立的新目录；不要用 ZIP 覆盖已有数据目录。
- 侧栏连接本机工作台会建立扩展与本地 Bridge 的配对授权。需要真实 Edge 验收时，在你自己的测试档案下配对。
