# v1.0 RC3 · 外部 AI 模拟面试闭环

入口：工作台 → 我的机会 → 选择岗位 → 面试 → 去其他 AI 练一次面试。侧栏原有面试入口也会进入这里。

1. 点击“生成模拟面试提示词”，检查完整脱敏预览，勾选确认后下载 Markdown 文件。
2. 在用户选择的 AI 软件中上传或粘贴提示词。AI 按 6–8 轮逐题提问，支持暂停、跳过和结束。
3. 说“结束面试”，让 AI 按文件内 JSON 协议输出总结、优点、改进、下一步以及真实问答。
4. 回工作台原岗位，将最后的单个 JSON 代码块粘贴到“导入练习结果”，或选择 UTF-8 .json/.txt 文件。
5. 点击预览检查，核对目标岗位和内容，再确认导入。记录在面试页持久保存。

导出内容为当前岗位 JD、原始经历与已确认事实、已有公司背景，经本地脱敏处理。不带 API 密钥、原始简历附件或 HR 对话，不自动上传其他软件。导出/导入无需当前模型可用。

返回协议 schema 为 job-assistant.mock-interview.v1；package_id 原样保留。总结为字符串，strengths/improvements/next_steps 为字符串数组（各最多 10 项），turns 为 1–20 项 question/answer/feedback 字符串对象。错误 JSON、未知字段、跨岗位编号会被拒绝。确认前再脱敏；改变预览后的内容需重新核对。

同一练习包只接收一个结果，相同结果重复导入幂等；不同结果不覆盖历史，下一次练习请重新导出。源档案或岗位更新后，旧记录显示对应旧版本。

两张独立表随启动幂等建立，原资料不清空；本地资料副本与清空功能覆盖新表。练习记录不自动写入已确认经历、模型历史或实际投递/面试统计。

验证：隔离虚构资料浏览器实测导出预览、JSON 粘贴预览、确认保存、刷新恢复；测试覆盖隐私、格式限制、跨岗位、重复导入、旧资料标记和删除。未将真实简历上传外部 AI，未验证各家 AI 的实际输出遵循程度。
