# RC4.3.29 · 对话补充经历入档测试版

RC4.3.28 的聊天消息会保存在任务记录里，但用户在聊天中补充的经历不会自动成为长期已确认事实。对话 Agent 只读取有限的近期轮次，因此多轮后不能保证继续使用这段补充。

本版在已结束的本人聊天消息旁增加“记入经历”。工作台从本机任务记录取回该条用户原话，用户可删去提问或假设，只保留自己确认做过的事，勾选核对后写入 `profile_facts`。同一条聊天消息重复保存使用同一事实 ID，不重复增加记录。侧栏按钮只把任务 ID 带到工作台；经历正文不放进链接，也不通过侧栏开放档案接口。

事实保存后，档案版本更新，用户必须再次核对脱敏预览并确认，模型任务才可继续。后续新对话和深度分析的任务快照都包含该条已确认事实。已有任务不会被悄悄改写，旧报告按原有版本规则标为过期；删除事实仍通过工作台现有入口完成。Agent 被明确要求区分“本轮用户自述”和“长期已确认事实”，不得声称聊天已自动入档。

本版仍为 RC 测试版；真实 Edge 页面与真实模型连续对话效果需在同版服务和扩展中核对。
