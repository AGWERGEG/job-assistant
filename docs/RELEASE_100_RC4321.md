# v1.0 RC4.3.21 · 对话 Agent 整合测试版

本版将 RC4.3.20 的隔离对话 Agent 接入兼容 API 模式的普通聊天。不是正式 v1；不覆盖或迁移正在使用的安装目录。

## 使用变化

- 普通聊天以本轮问题为主；已确认岗位 JD 和经历通过工具按需读取，历史只保留同岗位/同资料版本最近四轮完成的普通对话。
- 不把历史专业报告作为聊天事实材料。历史后台任务以程序状态及来源记录提供。
- 本轮明确要求完整/详细分析时可创建后台分析任务；引用、转述、否定和条件句不会授权建单。守卫采用保守规则，未识别的表达可用现有“分析该岗位”按钮。
- 简历、HR 招呼、快捷分析、面试准备/复盘等现有快捷入口保留。Codex CLI 模式仍沿用旧路径；工具调用 Agent 当前适用于兼容 API 模式。
- 回复经复核后整体显示，等待期间仍可取消；不是逐字低延迟聊天。DeepSeek 对话/复核禁用思考，后台专业报告沿用原设置。
- 取消任务请使用界面的取消按钮，Agent 不支持用聊天执行取消、删除、投递或发送。

## 工程范围

新增 app/dialogue.py、dialogue_core.py、dialogue_child.py。父进程管理总时限、取消和脱敏；凭据仅经子进程 stdin，错误输出不包含原始 SDK 异常。

建单在 Store 的同一 SQLite 写事务中校验原始对话租约、隐私指纹、岗位版本、侧栏已确认目标；使用原始用户回合做幂等键，保留原始请求。模型改写不替代授权。建单后的模型失败会显示实际任务回执；不把报告已排队说成已完成。

仅带真实对话来源的任务标为 earlier_user_turn；其他已有后台任务只标 task_record。无需新增表或清库，原数据兼容。

复用现有侧栏 /bridge/talk 与工作台 /api/talk，无新增招聘平台权限；HR/JD 绑定核心未改。Bridge 只增加传入已确认客户端标识，版本标识同步更新。

## 安装与回退

macOS Apple 芯片便携 ZIP 内含 Python3.12、文档依赖及 pydantic-ai-slim[openai]==2.51.0。源码测试包需安装 requirements.txt，Python3.10+；建议Python3.12。

解压到独立新目录，启动新包，重载该包 extension 目录中的扩展并连接同版服务。原安装、资料和密钥不会被新包自动读取或复制。要沿用旧资料，先停止旧服务并备份，再通过 --data-dir 明确指定旧数据目录。不要将包内内容覆盖旧数据。

回退：停止新服务，重新启动原 RC4.3.20 安装并重载原扩展。也可在本机设置中保存 dialogue_agent=false 让兼容API普通聊天使用旧路径；此开关未新增UI，开发者可经现有鉴权 /api/companion 接口修改。错误不会自动切换旧提示词而重复发送资料。

## 验证与限制

详见随包测试记录和脱敏真实 API 证据。离线断言、HTTP/worker真实API测试与招聘站点Edge验收分别记录。

对话事实复核与程序守卫能降低已知错误，不能保证模型永不推断过度；后台专业报告仍需人工核对，尤其“协助制作”与独立能力、资料未提及与真实缺口。未验收多模型表现、真实招聘Edge联动、Windows/Intel Mac新版包、签名/公证。
