# RC4.3.38 · 企业研究预览与对话闭环测试版

本版补齐企业信息能力的用户可见闭环。

## 功能

- 工作台公司资料面板增加“研究这家公司”按钮、问题输入、研究预览卡、来源列表和确认保存/取消操作。
- 用户明确询问企业产品、业务、客户、发展或风评时，普通聊天自动触发受控公开研究；不要求用户先手动补抓公司背景。
- 研究来源、事实、警告、来源类型、可信度和观察时间进入本轮 Agent 上下文。
- 研究预览默认不写入公司材料；只有用户点击确认保存后才入库。
- 已保存公司 dossier 继续进入普通聊天上下文，企业资料和岗位 JD、候选人经历保持分层。

## 安全边界

只读公开 HTTPS；拒绝招聘平台、Cookie、登录态、私网地址和非公网 DNS；限制 TLS、重定向、响应大小和总超时。公开研究失败时给出可操作提示，不伪造企业结论。

## 验证

- Python 完整回归：206 项通过。
- Node 工作台与扩展回归：139 项通过。
- 新增 UI 测试覆盖研究预览、来源显示、确认保存和取消不入库。
- 新增对话测试覆盖研究来源进入 Agent prompt、网络失败提示和不创建 analyze_job。
- 便携包冒烟与发布包隐私检查按 RC 流程执行。

## 限制

本版仍是 v1 RC 测试版，不是正式 v1。真实公开网络研究受来源可用性、搜索供应商配置和网页变化影响；不会自动登录招聘平台或访问私有员工评价。
