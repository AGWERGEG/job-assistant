# v1.0 RC4.3.4 智联在线简历读取修复

日期：2026-09-23。此版本是源码与扩展测试包，不是正式版或便携运行包。macOS 便携包仍为 RC4.3.2。

## 触发与修复

在已登录的 `https://i.zhaopin.com/resume` 点击“读取智联在线简历并核对”，RC4.3.3 返回“栏目未能唯一定位或尚未加载完成”。真实页面的正文栏目使用 `diagnosis-scroll` 类名，旧排除规则误过滤正文；`jobs-bar` 栏目导航却被当作正文标题。修复后只在智联分支排除栏目导航，并保留正文容器。页面的“证书”标题也纳入已有证书栏目。

继续核对发现，旧代码把多个求职意向和工作经历合并成各一条。现在分别按当前页面的 `.wanna-title__job-container` 和 `.job-exp-pre-item` 逐条读取；空栏目的“添加…”与“查看全部”等操作文字不进入草稿。BOSS 在线简历解析仍使用原有规则。

## 验证证据与边界

- Python 回归：106 项通过。Node 回归：90 项通过；新增虚构结构用例覆盖导航重复、正文 `diagnosis-scroll`、多条求职意向/工作经历、空栏目和重复正文标题拒绝自动选择。
- 当前 macOS Edge 智联简历页，修复脚本同步至已加载的测试扩展并重新加载后，点击读取成功进入工作台本地草稿核对。草稿显示 4 个有内容栏目：个人优势 1 条、求职意向 3 条、工作经历 2 条、教育经历 2 条；项目经历、证书、其他经历显示为空。
- 现场验证使用 RC4.3.4 相同的提取脚本及当时运行的 RC4.3.3 本机服务；RC4.3.4 完整新解压包尚未单独启动。没有点击“加入编辑器”或保存正式档案，没有调用模型。
- 本轮未验证其他智联账号/页面版式，也未完成智联公司资料保存与分析引用的真实 Edge 闭环，58 登录后实站复测仍待做。

## 测试安装

把 RC4.3.4 源码测试包解压到独立目录，按 README 安装依赖并启动本机工作台；在 Edge 扩展管理页加载包内 `extension/`，刷新智联简历页并连接本机工作台。旧 RC4.3.3 ZIP 保留为历史测试包，勿把两个版本的扩展目录混用。包不包含 `data/`、`data-demo/`、SQLite、API 密钥或浏览器配置。
