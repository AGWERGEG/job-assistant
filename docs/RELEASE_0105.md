# v0.10.5 · 三步快速入门

这一版不增加求职能力，专门降低第一次使用的理解成本。

## 首次使用路径

1. 侧栏打开工作台。
2. 工作台进入聚焦模式：连接模型 → 选角色与称呼 → 保存真实经历 → 核对脱敏。
3. 返回 BOSS，打开一个岗位。侧栏只显示“就看这个，帮我分析”。
4. 用户点击后，系统先确认岗位，再发起第一次快速判断。
5. 简短结果出现在侧栏后，可当场结束引导。

深度分析、简历优化和面试准备卡不再是首次引导的强制环节，用户有真实需求时再用。

## 交互改动

- 首次引导期间隐藏工作台常规导航、档案补充和数据管理等无关内容。
- 每一步只保留当前表单和一个主动作。
- “保存接入方式”与“测试连接”在引导中合并；测试失败不进入下一步。
- 角色选择固定为两张卡片，其他个人设置在首次流程中隐藏。
- 工作台返回 BOSS 时会尝试关闭扩展打开的标签页；若浏览器阻止，会提示手动切回。
- 已有用户的正常工作台、侧栏快捷键和历史数据不受影响。

## 边界

- 引导仍不会自动确认岗位、自动发起模型任务、自动投递或发送 HR 消息。
- “就看这个，帮我分析”只在用户点击后依次确认岗位和创建快速判断。
- 独立岗位详情页的历史识别问题仍保留为已知项，本版未扩大开发范围。

## 验证

- Python：80 项通过。
- 扩展与工作台 JavaScript：44 项通过。
- 覆盖连接测试门槛、聚焦模式、单击确认并分析、第一次有效回复后结束引导。

## 更新方式

1. 替换工作台文件并重启本机服务。
2. 在 `edge://extensions` 对已加载的 `extension` 目录点击“重新加载”。
3. 刷新 BOSS 页面。服务重启后原配对会话失效，需要重新生成配对码。
