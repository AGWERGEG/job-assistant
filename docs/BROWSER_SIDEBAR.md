# v0.4 BOSS 浏览器侧栏

> 当前版本为 **0.5.0 陪伴闭环内测版**。先读 [v0.5 使用与工程交接](V05_HANDOFF.md)。下方0.4及更早说明为历史记录；界面、脱敏、接入与验收范围以v0.5为准。

这是 Chrome / Edge 的 Manifest V3 扩展。Codex CLI 继续负责本机推理，用户在 Chrome / Edge 浏览 BOSS。它不能直接安装到 Codex 内置浏览器。本机开发环境未检测到 Chrome / Edge，发布包属于可加载内测版本，尚未完成真实扩展运行与 BOSS 登录态页面验收。

## 安装与连接

1. 解压完整项目，启动本地服务。旧用户使用原有数据目录，不覆盖 data 或 data-demo。
2. Chrome 打开 `chrome://extensions`，或 Edge 打开 `edge://extensions`。
3. 打开开发者模式，选择“加载已解压的扩展”，选项目中的 `extension` 文件夹（不是 ZIP）。Chrome 最低版本 116；Edge 需支持 sidePanel API 的版本，实际兼容待测。
4. 在本地工作台点击“生成五分钟配对码”。
5. 点浏览器工具栏的“求职搭子”扩展图标，侧栏填写端口和配对码，点击连接。
6. 回到 BOSS 刷新一次页面，使新安装的采集脚本加载；手动登录。此扩展不读取 Cookie、密码或验证码。
7. 打开职位详情，确认侧栏中的职位、公司和来源链接正确，然后点击判断岗位、改简历或准备回复。

配对码一次性、五分钟有效。连接凭据仅存扩展后台的会话存储，页面脚本拿不到它；本地服务重启或浏览器重启后重新配对。工作台“断开扩展”撤销全部已配对客户端。

## 跟随浏览

侧栏打开并可见时，每秒询问当前页面是否发生变化。页面采集脚本用 MutationObserver 标记变化，只读取职位区域。详情稳定至少 800ms 后采集，侧栏切换到新岗位。开启“跟随浏览自动分析”后，再停留约 2 秒触发岗位判断；未开启时只识别岗位。

自动调用会消耗用户 Codex 登录额度。本地每个扩展客户端至少间隔 12 秒自动创建任务；快速浏览期间以页面识别为主。侧栏关闭后不再轮询；已经开始的模型任务可能继续完成，不会被强行中断。

首版没有独立快速模型，仍使用 v0.3 的完整岗位判断；“页面识别快”不代表“模型秒回”。耗时取决于本机 Codex 服务，尚未实现增量流式输出。

## BOSS 页面适配范围

优先支持独立 `/job_detail/岗位ID.html` 职位页。列表右侧详情仅在同时提取到唯一详情容器、岗位名称、公司、完整 JD 和唯一职位链接时使用。多详情、内容太短、岗位 ID 缺失或链接冲突均停止采集并提示，不从整页列表猜 JD。

由于真实 BOSS 页面本轮读取超时，当前选择器是初版候选，需要在用户实际浏览器验证。若无法识别，先打开独立职位页；仍不成功时，在网页选中 JD，侧栏点“读取选中 JD”，补职位名/公司并使用。这是一次性补充，不用返回工作台。

不调用 BOSS 私有 API、不导出登录态、不移除网站安全头。隐藏文本不进入采集正文；来源 URL 去掉追踪参数和令牌。页面布局或字体反爬变化仍可能影响正文，需要核对侧栏识别结果。

## HR 回复

在职位详情识别成功后点击“固定岗位用于聊天”，然后在同一标签页进入聊天。选中需要回复的最近消息，侧栏点击“读取当前网页选中文字”，预览并勾选“属于固定岗位”，再点“准备回复”。

首版使用显式选择，尚未自动识别 HR 会话 ID。切换浏览器标签会清除岗位固定和聊天预览，防止串岗。不同 HR 会话之间必须重新选择消息并核对绑定岗位。只复制回复，不向 BOSS 输入框写入或发送。

## 缓存和结果绑定

岗位以平台岗位 ID 标识。相同内容反复采集不增长 revision。结果缓存键包含提示版本、岗位 ID、岗位版本、画像版本、功能、补充要求和对话摘录。返回旧岗位可复用已完成结果；资料改变后缓存不再命中。

侧栏生成 scope 与递增 seq，后端拒绝过期采集和过期请求；前端在请求返回后再核对当前页面。切换岗位取消当前 scope 尚未执行的自动任务；已运行的结果保留到原岗位，不能覆盖新岗位。

当前默认启动 2 个 Codex worker，显式任务优先于自动任务；每个任务仍由独立临时 Codex 会话处理，不会中断已经运行的推理。可用 `--workers 1` 降低额度并发，或通过 `JOB_ASSISTANT_WORKERS` 配置。

为缩短首屏等待，worker 默认使用 `gpt-5.6-luna` + `low` 推理档；可通过 `JOB_ASSISTANT_CODEX_MODEL` 和 `JOB_ASSISTANT_CODEX_REASONING` 切回其他模型/推理档。结果质量仍需以用户实际岗位评测为准。

## 开发与测试

核心：`python3 -m unittest discover -s tests -v`。

扩展 JS 页面逻辑测试：安装 jsdom@26 到临时依赖目录，再设置 NODE_PATH：

```bash
npm install --prefix /path/to/scratch jsdom@26
NODE_PATH=/path/to/scratch/node_modules node --test tests/test_extension.cjs
```

这些测试使用合成 DOM 和模拟 chrome API，不是实际浏览器扩展 E2E。真实验收：在 Chrome/Edge 完成加载、配对、10 个实际职位切换、A→B 晚返回、缓存、自动分析开关和选中聊天预览。现有本地工作台仍可继续使用。
