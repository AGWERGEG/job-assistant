# v1.0 RC4.3.2 · 跳过引导后的就绪状态修复（macOS）

## 修复内容

此前首次使用者选择“跳过引导”后，教程会结束，但如果尚未补充经历或确认脱敏档案，侧栏的分析、简历、HR 招呼和发送按钮会处于不可用状态；用户只能看到灰色按钮，难以知道下一步。

本版将“教程是否结束”和“是否可以向模型发起任务”拆开：

- 本地服务以 `profile_required`、`privacy_required`、`ready` 返回不含简历正文和密钥的就绪状态。
- 侧栏在未就绪时显示原因、简短说明和“去工作台补充档案 / 核对脱敏”按钮。
- 工作台跳过引导后会直接进入“我的档案”，而不是把 API 设置误当成完整配置。
- 输入框下方同步显示当前阻塞原因；使用快捷键尝试发送时也会明确提示，不再静默返回。

已有用户的数据、模型接入、配对关系和聊天草稿不会被删除或重置。

## macOS 升级

1. 停止旧版本并完整解压 RC4.3.2 到新目录；不要用空 `data/` 覆盖旧数据。
2. 如需保留旧档案，启动时将 `--data-dir` 指向原数据目录，或先复制旧目录备份。
3. 在 Edge/Chrome 的扩展管理页重新加载新目录中的 `extension`，刷新 BOSS 页面后重新配对。
4. 验证路径：跳过引导 → 保存模型接入 → 打开侧栏。此时应看到“还差一步”的说明卡，而不是只有灰色发送按钮。
