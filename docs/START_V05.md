# v0.5.0 怎么开始测试

1. 停止旧工作台。新用户双击“启动求职搭子.command”（Windows用.bat）；已有数据用新版 launch.py --data-dir 原数据目录 启动，避免进入一份空档案。
2. 打开 http://127.0.0.1:8421 。选择温柔/直球角色、填写称呼并保存。
3. 上传简历或使用填写模板，核对经历，保存本地档案。真实姓名字段只作脱敏用。
4. 查看脱敏预览，把遗漏的人名、地址等加进“额外隐去的信息”。确认后建档。修改档案或敏感词需要重新确认。
5. 展开接入设置，选择本机 Codex 或兼容API。API填写地址（例如https://供应商域名/v1）、模型和密钥，先保存再测试。仅支持Chat Completions格式；专业任务不支持JSON模式的服务可取消勾选。
6. 没有岗位时也能在工作台聊近况。有岗位时可手动保存，或重载Edge/Chrome中本项目extension目录，确认侧栏显示0.5.0后重新配对。
7. 侧栏“确认这个岗位”后再聊天。三个快捷键可单独使用；“帮我优化简历”等明确请求也可从聊天发起。
8. 简历结果在工作台定位到对应任务，核对、编辑、保存验收版；HR招呼留在对话里。深度分析从工作台发起。

本机已知情况：2026-09-17测试时Codex CLI已登录，但实际请求返回使用额度已耗尽。需要额度恢复，或自行配置可用API；本版没有附带第三方密钥。测试连接不会上传简历。

当前仍未实现：流式输出、PDF/Word成稿导出、全量个人资料删除、独立面试事件卡、成功统计和彩蛋。独立职位页识别仍按已知问题搁置，可在工作台手动保存JD或用侧栏选中JD入口。

本地脱敏采用规则和自定义敏感词，并非匿名保证。出站预览保留必要职业事实；请核对未标注的人名、地址及可识别的独特经历。
