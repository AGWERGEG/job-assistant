# v1.0 RC4.3.6 岗位与 HR 会话关联修复

日期：2026-09-24。当前已构建源码/扩展测试 ZIP `outputs/JobAssistant_v1.0_RC4.3.6_岗位HR关联修复_源码扩展测试包.zip`，共 133 个白名单文件；未构建 macOS/Windows 便携包，未替换用户正在运行的服务或扩展。不是正式版。

## 根因

BOSS 的不同 HR 会话共用 `/web/geek/chat`。旧实现仅用聊天 URL 查关联记录，没有当前招聘者、企业及岗位的身份信息。因此换到第二位 HR 后仍可能显示第一条岗位关联；同一岗位的不同 HR 也不能由 URL 区分。侧栏固定的对话目标又独立于浏览页面，两者缺少核验提示，进一步放大了错位。

## 已实现

- 当前会话按招聘者姓名、企业、岗位生成身份；页面提供公开 JD 链接时，进一步纳入平台岗位标识并验证与本地 JD 一致。URL 本身不能证明关联。
- 企业和岗位名称规范化后精确匹配；采集过 JD 招聘者姓名时再独立核对姓名。不一致时服务端拒绝保存，即使用户选中了该岗位也不能强行绑定。JD 缺少姓名证据时界面明确提示人工核对，不能声称姓名已独立验证。
- 从已确认 JD 进入 HR 页时，显示匹配候选并要求明确绑定；直接进入历史 HR 会话时查询本地绑定或候选 JD。已绑定但当前对话目标不同，需点击“使用此会话关联的岗位”，不自动换目标。
- 没有匹配 JD 时提示打开完整岗位页面建档；不把聊天摘要当作 JD。
- 支持解绑与重新绑定；解绑不删除岗位、分析或本地对话。跨岗位重新绑定前必须先解绑。
- 切换会话立即清除旧卡片，稳定后重新核验；异步响应返回时重读当前会话，拒绝旧结果覆盖。保存、解绑和返回 JD 前也重新核验。
- 未关联到当前岗位时禁用快捷岗位操作；普通聊天仍明确针对上方固定岗位。有效关联后可对该岗位使用快捷操作；不会自动读取 HR 消息正文作为模型上下文。
- 内容不变时不重绘关联卡按钮，避免轮询造成视觉跳动和焦点丢失。
- 新增 `job_recruiters`、`hr_chat_bindings` 表，schema 11；旧 `job_links` 记录保留并显示“待重新核验”，不自动迁移为可信绑定。资料副本与清理包含新表。
- 扩展与服务增加 `verified-chat-links` 能力检查；新侧栏遇到旧服务时禁用关联并提示同时更新。源码版本为 `1.0.0-rc.4.3.6`，扩展数字版本 `1.0.0.13`。

- Node 完整回归：103 项通过，包含扩展、工作台及站点适配；新增覆盖旧卡清除、旧响应迟到、缺少 JD、历史会话显式切换、旧服务兼容阻断和不重复重绘。
- 真实本地 HTTP 服务器使用临时数据库验证：配对、capture/confirm、link-save/context/unbind、版本与能力标记；未配对写入被拒绝。
- Codex 内置浏览器的独立虚构测试页验证：换 HR 后旧卡清除、无 JD 时按钮禁用、历史绑定手动切换后快捷按钮恢复；390px 宽侧栏布局可用。页面接口为测试替身，此项只验证真实浏览器中的界面交互。
- 未调用外部模型，未更改用户库，未刷新或切换用户的 Edge 页面。

## 未验证与限制

- 新代码与真实 BOSS DOM、Edge MV3 扩展和同版服务的完整联动尚未验收；不能将合成 DOM 或本地测试页当作实站通过。
- 当前 HR 关联核验仅适配 BOSS。智联与 58 岗位功能保留，但未新增其聊天会话绑定适配。
- 无公开岗位链接/稳定会话 ID 时使用姓名、企业、岗位组合；不同招聘者同名、同公司且岗位同名时缺乏充分唯一性证据。当前实现提供候选与人工核对，不代表平台账号级身份认证。
- 企业简称或岗位标题差异可能导致不匹配。遇到这些情况应补充页面证据，不能绕过核验强制关联。
- BOSS 通用聊天链接不能保证自动定位某位 HR。工作台入口明确提示仍需选择该 HR；不自动操作平台联系人列表。

## 最小实站验收

1. 在独立目录构建并加载同版服务/扩展，使用隔离数据；保留用户当前运行实例。由用户在方便时完成一次新版页面打开，不反复刷新。
2. 用户自行打开 JD A 并确认建档，再自行进入 HR A。核对企业、岗位和 HR 姓名后绑定。
3. 用户自行打开 JD B / HR B。侧栏不应继续显示 A 的关联卡；企业或岗位不一致时应拒绝绑定 A。
4. 用户自行回到历史 HR A；应查到 A，并提供明确切换岗位入口。解绑后查找应无有效关联，重新绑定后恢复。
5. 未建档 HR C 应提示打开 JD；切换 HR 的加载过程中和快速点击时，旧响应不得覆盖当前卡片。
6. 核对工作台链接记录中的 HR 姓名和岗位、旧记录待核验标签。全程不代用户打招呼、发送消息或投递。
