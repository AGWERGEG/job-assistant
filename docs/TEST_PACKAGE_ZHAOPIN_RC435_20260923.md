# 智联公司岗位卡片修复源码测试包 · v1.0 RC4.3.5

这是供 Edge 测试的源码与扩展 ZIP，不是正式版或便携安装包。修复范围、证据和限制见 [RELEASE_100_RC435.md](RELEASE_100_RC435.md)。

解压到新的独立目录，启动其中工作台，并在 Edge 加载其中的 `extension/`；停用旧扩展、刷新招聘网页后重新连接。确认一个智联目标岗位，再打开**同一公司 ID**的“在招职位”页：侧栏应显示当前已加载卡片数量，点击“补充这家公司的背景”后到工作台核对来源。卡片只含标题、链接、薪资与页面可见条件，不代表完整 JD；其他公司推荐不应进入材料。不要为了测试把智联公司卡片存到当前 BOSS 目标上。

当前实站只验证了两张卡片的读取；真实用户工作台保存及模型分析仍待验收。ZIP 白名单不包含 `data/`、`data-demo/`、SQLite、密钥、浏览器配置或依赖缓存。
