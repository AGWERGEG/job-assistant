# v0.10.2 工作台信息收敛

2026-09-18。本轮调整工作台的信息层级，不修改任务、证据、简历、进展或模型上下文的数据结构；浏览器侧栏继续使用 0.10.0。

## 使用变化

- “继续聊”首页把后台任务放入一行摘要，显示处理中、需要处理和待查看数量。默认展开后只列最近三项，可再查看全部；已查看结果仍按原开关显示。
- “我的机会”左栏增加岗位/公司搜索和收起按钮。收起偏好保存在浏览器本地；窄屏选中岗位后自动收起，正文获得更多空间。
- 公司与业务背景默认收起，摘要显示公司和材料数。展开后按公司介绍、产品与业务、招聘概况、同公司岗位参考分组；材料编号、采集时间和原文放在二级详情中。
- 公司材料说明模型任务每次最多选择最近且相关的 10 条；其余原文仍保存在工作台，不再让“已保存材料总数”看起来等同“全部送入模型”。
- 深度分析按钮在没有结果时显示“生成详细岗位分析”；已有结果时显示“查看详细分析”，生成中显示“查看分析进度”。重新分析入口放在最新完成结果旁，避免查看时意外再次调用模型。

## 状态边界

折叠、搜索和展开只改变当前浏览器显示，不自动标记任务已查看，不删除材料，不验收简历，也不记录投递或面试。机会栏收起偏好保存在 localStorage；未保存聊天与简历草稿的既有边界未改变。

## 验证

新增高密度工作台测试：14 个待查看任务默认只显示三项且可恢复全部；多岗位可搜索和收起；8 条公司材料按两类汇总且全部仍可访问；已有深度分析只打开结果、不调用 `/api/talk`。完整验证为 77 项 Python 与 41 项 JS（32 项扩展、9 项工作台）。

实际浏览器使用现有本机数据检查：14 条待查看任务显示为一行摘要；27 个机会可收起；17 条公司材料汇总为 4 类，展开和底部收起均可用。测试未创建模型任务、未记录求职进展、未改简历内容。
