# RC4.3.19 · 深度 API 传输诊断与结构化流式修复测试版

本版基于 RC4.3.18，修复兼容 API 深度任务在长响应连接提前中断时被统一显示为“模型接口未返回有效内容”的问题。

## 修复内容

- 当兼容 API 的流式能力已经通过连接测试确认时，结构化后台任务可使用 SSE 接收响应；程序只有收到完整的 `[DONE]` 事件后才解析 JSON，不把 JSON 片段写入聊天区。
- 流式任务缺少结束标记、正文为空、服务端声明截断或流式接口报告错误时，任务明确失败，不会把不完整 JSON 当成结果保存。
- 非流式响应按 `Content-Length` 检查传输完整性。响应提前关闭、长度不完整、协议异常和连接中断分别保留可诊断错误类型。
- API 子进程不再把所有未知异常都伪装成“模型接口未返回有效内容”；仅输出异常类型和可操作提示，不保存原始响应正文或密钥。
- 任务指标记录本次使用 `stream` 或 `complete` 模式，以及是否为结构化 JSON 任务，便于后续验收。

岗位与 HR 关联、提示词预算、脱敏和数据存储边界没有改变。

## 验证边界

- `tests/test_rc_transport.py` 本地 HTTP 模拟 11 项通过，覆盖结构化 SSE、缺少 `[DONE]`、响应中断、格式异常、流式回退、取消和用量传递。
- 需使用便携包内 Python 3.12 运行完整测试；系统 Python 3.9 缺少项目要求的依赖，不能作为完整回归基线。
- 尚未调用真实 API 验证服务商是否允许结构化 SSE；需要在工作台重新测试连接后，再用一次深度岗位分析确认结果。
- 本版仍是 RC 测试版，不是正式 v1。
