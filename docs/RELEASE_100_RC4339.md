# RC4.3.39 验收与发布候选说明

日期：2026-10-06（Asia/Shanghai）。本版基于 RC4.3.38 的源码包，在用户指定的“rc基线发散”目录独立开发；原包与原有使用中的数据未修改。

## 发布结论

可以交付新一版 RC 测试包，尚不能宣布正式 v1 可发布。阻塞项是企业自动检索的覆盖和稳定性：免密钥来源对 OpenAI 可取得来源，对有赞没有取得有效资料；已实现 Tavily 搜索 API 接入，但没有可用密钥做真实验收。已保存企业材料的读取已通过真实模型验证。相同版本的 BOSS/智联/58 登录后完整扩展联动没有在本轮重新验收。

## 实现与修复

- 普通讨论、明确创建专项任务、引用旧成果分别处理。“分析分析”及 HR 风险讨论保留在聊天；有效模型授权直接参与本机建单校验，规则只兜底。普通聊天不提供创建任务工具，避免模型重复尝试后生成权限提示。
- / 菜单只引用成果；选择具体任务 ID，可见类型、序号、日期。已选成果的讨论不能创建新任务，岗位切换清除引用。工作台和侧栏均可在原处展开正文与详细依据，保留独立的机会页入口。
- 用户补充经历仅产生待核对提示。手动记入经历和模型候选均须确认，保存后重新批准脱敏；新快照包含已确认事实，旧报告显示过期。
- 企业研究无需先手动采集；使用已确认岗位的公司名与有限公开主题查询，不把聊天原文或个人经历交给搜索来源。已有企业材料与新网络来源分开处理。来源为空且无旧材料时由程序返回可操作提示，不让模型补写无来源结论。
- 研究预览由服务端保存，确认只提交预览标识；取消、超时、岗位变化和公司身份变化会使预览失效。未关联招聘平台公司标识的研究限定在当前岗位；岗位公司或网址变化后不使用旧研究。重复来源去重；已有来源与最多五条新来源可一起预览，新来源优先进入受限上下文。
- 企业来源的脱敏与预算在最终快照统一检查；保留安全公开来源与不透明引用 ID，避免新增材料绕过隐私过滤。
- 研究来源在设置页独立配置、保存与测试；密码不回显，不改变模型任务指派。BOSS 返回按钮在用户点击时立即打开页面，同时提供直接链接兜底。

| 扩展侧栏 | 合成 DOM / Node 回归通过；同版扩展完整实站 E2E 未验证 |

真实模型验收：

- HR 热情/面聊/薪资压力担忧 + “帮我分析分析”，及其后单独“分析分析”：不增加分析任务，能承接前文。
- HR 引用、否定、假设、JD 指令、好/可以：不建单。引用转述复测没有调用创建工具。
- 指定旧分析：数据库 reference_task_id 与所选任务一致，回复承接该结果，不建单。
- 补充经历：模型产生候选但不自动入库；未确认被拒绝；确认保存后隐私批准失效；重新批准后新对话能使用该事实，旧成果标为过期。
- “结合我刚保存的经历，再对这个岗位做一次详细分析”：旧规则返回 false，真实意图模型返回 analyze_job，数据库恰好创建一个子任务；相同请求重发返回同一父任务。子任务原话、岗位、已确认经历正确，后台报告完成。
- 已保存的合成企业介绍可被真实模型读取并标为未核实企业自述，没有因为外网失败就声称所有材料为空。
- 没有手动公司背景时，OpenAI 公开检索取得五条带 URL 的来源，预览和显式确认保存通过。有赞同场景没有取得有效来源，此项未通过。

模型超时/无效 JSON、跨岗、隐私变化、取消和不可篡改预览通过故障注入测试；这些不是实际服务商故障或真实平台端到端证据。原始真实模型的模型生成内容仍需要用户核对。

## 使用与后续验收

1. 解压 macOS Apple 芯片便携测试包，双击“启动求职搭子.command”。保持服务、网页与扩展版本一致。
2. 原有真实数据需沿用既有启动/迁移流程，不要复制到包中；本次没有迁移或打开用户数据。
3. 设置 → 公司研究的搜索来源，可选择 Tavily，保存密钥后测试。没有搜索密钥时仍可试免密钥来源，但成功测试一个公司不能保证所有公司可用。
4. 取得 Tavily 可用接入后，用没有手动背景的有赞岗位复测：自动获取相关来源、回复引用来源、取消不保存、确认后用于下一次对话与分析。
5. 正式发布前还需完成同版实际扩展联动及用户最终验收；本版没有签名、公证、安装器、自动更新或扩展商店发布。
