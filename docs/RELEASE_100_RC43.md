# v1.0 RC4.3 · 侧栏自动发现与确认连接

本轮解决非技术测试用户不知道如何启动、复制配对码和填写端口的问题。RC4.2 的模型输入预算、Token 用量和重试计时继续保留。

## 新连接流程

1. 侧栏自动检测本机常用端口上的求职搭子服务。
2. 用户点击“连接我的工作台”。
3. 侧栏创建一个五分钟的一次性连接申请，并自动打开工作台确认页。
4. 工作台显示扩展标识摘要、权限说明和确认复选框。
5. 用户点击“连接这个侧栏”后，侧栏轮询取得只绑定当前扩展来源的 Bridge Token，并自动继续首次引导。

普通流程不再要求复制配对码或理解端口。原有配对码入口移动到侧栏和工作台的高级诊断区域，作为旧版兼容和故障兜底。

## 安全边界

- 自动发现接口只返回服务版本和支持的配对方式，不返回档案、岗位、设置或密钥。
- 连接申请绑定完整 `chrome-extension://<id>` 来源，其他扩展无法领取。
- 扩展提交申请不会自动授权；批准接口仍要求工作台本地会话令牌和用户明确勾选。
- 批准后的 Bridge Token 仍只保存在浏览器 session storage，浏览器或本地服务重启后需重新连接。
- Bridge 继续只开放岗位采集、受限对话、公司资料和在线简历草稿等窄接口，不能访问工作台设置、模型密钥或任意文件。

## 启动器边界

侧栏已增加“打开 / 启动工作台”入口：当服务已运行时直接打开；未运行时会提示用户启动本地程序。普通 MV3 扩展不能直接执行 macOS/Windows 程序，因此本版尚不包含真正的一键系统启动。后续安装版可通过 `jobassistant://start` 协议或 Native Messaging 实现。

## Windows 便携包

RC4.3 同步提供 Windows 10/11 x64 便携免安装版。它复用此前测试包中的 Python 3.14 x64 运行环境与 python-docx、pypdf、ReportLab 等依赖，但程序源码、扩展和页面均替换为当前 RC4.3。启动脚本优先使用内置 `runtime/python.exe`，通过 `PYTHONPATH=packages` 加载依赖，并支持透传 `--data-dir`、`--port` 等参数。

构建脚本会忽略旧ZIP顶层目录名的历史编码，重新生成标准UTF-8目录名；同时检查运行环境、文档依赖、扩展、启动脚本及发布包内无 data、SQLite、密钥或缓存。本轮构建环境是macOS，不能运行Windows PE程序，因此Windows真机启动、Edge侧栏、中文PDF字体与安全软件提示仍需目标电脑人工验收。
