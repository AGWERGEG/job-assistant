# v1.0 RC4.3.14 RC4.3.7 绑定基线 + UI 重构

用户已实测 RC4.3.13 的 JD/HR 关联可用，要求冻结核心判断，仅重构原 UI。

本版保持 RC4.3.7 的 `extractor.js`、`content.js`、`background.js`、`app/chat_links.py` 和 `app/bridge.py` 不变；仅将 RC4.3.8 的侧栏 UI 编排移植到 RC4.3.13：

- 当前 HR 与固定岗位不同，在岗位栏附近显示“切换到此岗位”；
- 关联一致时不显示常驻关联卡；
- 返回岗位、解绑、重新绑定和候选核对放入“HR 会话关联 · 高级设置”；
- 不改变会话识别、后端绑定核验、配对和聊天正文边界。

Node 扩展/工作台 UI 回归通过；核心文件与 RC4.3.13 基线字节一致。系统 Python 3.9 下的 Python 检查不作为结论，正式检查需使用项目内 Python 3.10+。
