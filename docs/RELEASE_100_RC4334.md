# RC4.3.34 · 结果展示与引用界面修复测试版

本版针对 RC4.3.33 的界面反馈完成三项调整。

- `/` 输入只显示当前岗位已完成的专项成果引用，不再显示“/简历”“/深入分析”“/面试”“/HR沟通”的重复建单入口。新任务继续通过聊天区四个明确快捷按钮创建；引用仍传递结构化 `reference_task_id`。
- 专项结果使用“简历 1”“分析 2”“面试卡 1”“HR沟通 1”等用户可读名称，内部 `tailor_resume`、`analyze_job`、`suggest_reply` 只保留在程序路由层。序号按岗位与任务类型稳定递增，日期仅作为弱化辅助信息。
- 工作台任务卡和侧栏聊天卡可以在当前页面展开详细长文本；工作台另提供“在我的机会查看”，侧栏另提供“在工作台查看完整结果”。正文统一使用安全 Markdown 子集渲染，去除 `#`、`*` 等裸标记，不执行 HTML 或链接。

## 验收

- Python 对话/意图与任务展示回归通过；完整回归需使用项目规定的便携 Python。
- Node 工作台与扩展回归：108 项通过，覆盖 `/` 仅引用、中文任务名、当前页展开、侧栏 Markdown 展示和独立跳转入口。
- 保留 RC4.3.33 的真实 DeepSeek 意图与结果引用证据；本版没有重新调用用户 API 密钥。

## 限制

本版仍是 v1 RC 测试版，不是正式 v1。真实招聘网站 DOM 与用户当前 Edge 页面未被操作；Node 测试使用隔离 jsdom，不替代真实 BOSS 页面现场验收。
