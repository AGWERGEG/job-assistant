# RC4.3.5 Windows 便携测试包

这是 Windows 10/11 x64 的免安装测试包，不是正式版。完整解压后双击“启动求职搭子.bat”；包内自带 Python 和文档依赖，无需另行安装 Python。Edge 中仍须手动加载包内的 `extension/` 文件夹（`edge://extensions` → 开发人员模式 → 加载解压缩的扩展），旧版扩展应先停用。首次连接侧栏时在工作台确认配对。

本轮增加空白档案快速进入岗位分析、可搜索的切换岗位列表、岗位详情/HR 聊天网页链接记录，以及侧栏返回岗位详情入口。空白档案不会生成虚假履历；个人化任务仍需用户补充资料并完成脱敏确认。HR 聊天链接必须由用户手动记录，不按公司或 HR 名称推断岗位。

自动测试：Python 110 项通过、2 项因 Windows 平台跳过；Node 95 项通过。包已在独立临时目录解压启动，`/api/health` 返回 `1.0.0-rc.4.3.5`。真实 Edge UI、招聘站点联动、个人数据升级和真实模型调用尚未验收。测试前请备份旧版 `data/`，将本包解压到新的独立目录；不要把旧版 `data/` 覆盖到测试目录。测试包不包含用户数据、数据库、密钥和浏览器配置。
