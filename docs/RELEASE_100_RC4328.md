# RC4.3.28 · 深入分析入口与请求识别修复测试版

本版从 RC4.3.27 源码修订。工作台和浏览器侧栏的聊天快捷区都增加“深入分析”按钮；点击后按当前已确认岗位创建后台 `analyze_job` 任务。原“分析岗位”仍用于简短判断，输入 `/` 仍用于引用既有专项成果，不会因此创建新任务。

“深度分析一下该岗位”“深度分析一下”等独立、明确的用户请求现在直接进入后台分析任务，不依赖模型自行选择工具。引用、转述、否定和条件句不会命中这条直接路径；原有对话建单授权检查保留。Agent 的回退指引改为点击“深入分析”，避免把用户引到简短判断按钮。

工作台后台任务卡按钮统一显示“展开”。服务、扩展和静态资源版本均更新为 RC4.3.28。岗位与 HR 关联、脱敏和任务快照规则未变。

本版仍是 RC 测试包。合成回归与隔离启动只能验证程序路径；真实 Edge 页面与真实 DeepSeek 连续对话效果仍需在相同版本的服务和扩展中核对。
