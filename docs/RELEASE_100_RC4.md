# v1.0 RC4 · BOSS 在线简历显式导入

RC4.1 增加前后端能力握手：若用户只重载 RC4 扩展、但 8421 端口仍运行 RC3，侧栏会明确提示停止旧服务并启动 RC4.1，不再只显示“扩展接口不存在”。macOS 启动脚本也会继续传递 `--data-dir` 等参数，方便新版安全复用旧数据目录。

本轮增加一条独立于岗位自动跟随的资料入口：用户在 BOSS“我的在线简历”页面点击侧栏按钮，页面采集器才读取中间的在线简历栏目，并将结构化草稿保存到本机工作台。页面轮询、岗位识别和诊断均不携带个人简历正文。

读取范围包括个人优势、期望职位、工作经历、项目经历、教育经历、资格证书和明确的自定义经历。附件、头像、BOSS 简历诊断、隐私设置、推荐内容、页脚和 Cookie 不读取。平台已掩码的手机号、邮箱等不尝试还原；工作台会提示用户本机补充。“页面栏目为空”和“本次未能读取”使用不同状态，不能把加载失败解释成用户没有经历。

侧栏将草稿写入新的 `profile_import_drafts` 本地表后，打开工作台核对页。用户必须勾选确认，才可把草稿追加到档案编辑器。该动作不覆盖原姓名、偏好或经历，不自动保存，不调用模型，也不代表同意脱敏发送。用户仍需点击“保存本地档案”，再走原有脱敏预览与确认流程。

相同页面内容重复读取按指纹幂等复用草稿。资料副本与“删除本机全部求职资料”均覆盖导入草稿。Bridge 只新增窄接口 `/bridge/resume-import`，仍受扩展来源、配对令牌、Host 和 CORS 校验；工作台草稿读取仍需本地会话令牌。

合成 DOM 测试使用虚构资料，覆盖显式读取、被动快照不含正文、空项目、附件/诊断/掩码字段排除；后端测试覆盖来源与状态校验、幂等、原档案不覆盖、导出与删除；工作台测试覆盖核对前禁用、追加编辑器且不自动保存。真实 Edge 页面只做了只读结构检查，安装新版扩展后仍需用户重载扩展并完成一次人工验收。
