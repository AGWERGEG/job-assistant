# RC4.3.18 · 基于 RC4.3.17 的提示词预算修复测试版

本版以用户指定的 RC4.3.17 macOS Apple 芯片便携 ZIP 为基线。本地源码中的 `app/worker.py`、`app/store.py`、`extension/extractor.js`、`extension/panel.js` 与该 ZIP 对应文件逐字一致。保留原版岗位与 HR 会话识别、核验及显式切换规则，本轮没有改动这些判断。

## 修复

RC4.3.17 已在 `app/prompt_budget.py` 按岗位相关性挑选画像、确认事实、公司证据与历史结果，但没有核验最终 JSON 总长度，并把本轮 `instruction` 截到 3,000 字符。用合成的长 JD、HR 问题、十轮对话和确认事实复现时，聊天材料为 29,810 字符，本轮 4,000 字符要求仅发送 3,000 字符。

RC4.3.18 保留原有相关性选材，在脱敏后对最终序列化材料按任务种类设置字符预算：聊天 22,000—26,000，岗位分析 36,000，简历 44,000，面试准备/复盘 30,000—36,000，休息/结语 14,000。完整保留本轮要求；优先压缩旧对话、历史草稿、已验收简历和其他可选材料，确认经历单条正文有界。公司证据按脱敏后的实际内容去重，区别其他岗位列表、分类和筛选条件；证据编号及自述/平台生成/招聘方标签继续随选中的材料发送。极端必要材料仍超限时，本地明确报错，不把超预算请求发给模型。

`_prompt_budget` 只记录版本、预算与字符数，不含个人原文或密钥。预算按脱敏 JSON 的字符数计，不等于服务商 token 上限。数据库快照、原始资料、脱敏审核指纹和岗位关联没有变化。
