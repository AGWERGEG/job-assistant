# v0.10.3 首次使用引导闭环

2026-09-18。本轮将已有能力组织成一条可中断、可继续的首次使用路径；不新增招聘平台写操作，不自动投递、发招呼、确认岗位或创建模型任务。

## 新用户路径

1. 从 BOSS 侧栏打开“首次设置”，进入工作台。
2. 选择本机 Codex 或兼容 API；API 模式仍需要用户填写地址和模型名。
3. 选择“温柔搭子”或“直球搭子”，再设置称呼。
4. 上传或粘贴简历，在本地建档；姓名、联系方式与敏感词用于本地脱敏。
5. 预览并确认脱敏内容后回到 BOSS 侧栏。
6. 用户明确点击“确认这个岗位”，再点击快速分析或主动发起第一句对话。
7. 工作台在短回复完成后提供三选一：深入分析、岗位版简历、面试准备卡。
8. 后台任务完成且用户查看后，用户点击“结束引导，回到 BOSS”，进入日常使用循环。

侧栏只读取引导的公开进度（步骤和当前岗位标题/公司）；不读取原始简历、脱敏词、API 密钥或模型提示词。浏览其他岗位不会推进引导，也不会替换固定目标岗位。

## 兼容与恢复

- 已完成建档的旧用户自动视为已完成首次引导，不会被打断。设置页提供“重新查看首次引导”，它保留原档案、模型配置和既有任务，只重置引导进度。
- 刷新工作台、关闭侧栏或等待后台任务完成后，会根据本地任务状态恢复到对应步骤。
- 结束引导要求该用户亲自点击，且所选专业任务必须已完成；不把“生成”当作验收、投递或实际进展。

## 验证

- Python 单元测试 78 项：新增覆盖连接、角色、脱敏、显式岗位确认、首条对话、专业任务、完成限制和结束引导状态机。
- 浏览器侧栏与工作台 JS 测试 43 项：新增检查侧栏只展示入口、不自动确认；工作台按引导步骤定位到正确页面，既有用户仍落在“继续聊”。
- 本轮是本地自动化验证；升级后仍需用户在 Edge 扩展管理页重新加载扩展，刷新 BOSS 页面并重新配对（服务重启后配对令牌会失效）。
