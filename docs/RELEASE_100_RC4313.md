# v1.0 RC4.3.13 RC4.3.7 绑定链路恢复

用户实测确认 RC4.3.7 的 HR/JD 绑定可用，RC4.3.8 起持续失效。版本差异显示 RC4.3.8 将 `chatContext` 从 RC4.3.7 的“当前查看职位控件附近向上定位头部”改成全页薪资候选、泛化头部解析和多层扫描；同时改变了侧栏关联卡和重新核验时序。

RC4.3.13 撤回这组回归改动，恢复 RC4.3.7 的 extractor/content/panel 绑定基线，仅保留当前版本的启动端口和后端版本标记。目标是先恢复实际可用绑定，再单独设计不影响主路径的状态词兼容。

验证：RC4.3.7 原有聊天识别/扩展关键回归通过；RC4.3.8 新增高级设置 UI 测试不作为本恢复版验收。真实 Edge 需加载 RC4.3.13 扩展后重新验证。
