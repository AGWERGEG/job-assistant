# v1.0 RC4.3.8 HR 会话识别与切换提示修复

日期：2026-09-24。RC 测试版；未获正式版批准。

## 根因与改动

1. RC4.3.7 的会话头部解析依赖招聘职务关键词。“业务主管”等非白名单职务导致解析失败后，提取器继续向外遍历，把聊天主区前的联系人列表当作招聘者/企业。已用 RC4.3.7 交付 ZIP 中的代码复现：虚构页面返回招聘者“全部”，企业字段包含未读、新招呼、消息摘要及历史联系人；相同页面在新代码中返回正确的姓名、企业和岗位。
2. 新提取仅接受相邻、可见的短头部和职位条，支持分隔符、独立文本节点及三个明确字段的短行，不再依赖招聘职务白名单；限制头部长度、字段数和职位标题所在文本段，拒绝列表、消息标记及多候选。保留有/无“查看职位”及公开 JD 链接核验；无法唯一定位时停止关联。
3. 原版已能找到历史 HR 绑定，但“使用此会话关联的岗位”在常驻且限高滚动的大卡片内，入口容易被截断。新版在岗位栏下方显示简短的“当前 HR 会话 + 岗位 + 切换到此岗位”提示；只有用户点击才改变对话目标，关联一致后隐藏提示。切换到未绑定或读取不完整的会话时清除旧切换按钮。
4. 返回对应岗位、解绑、绑定核对和匹配候选移动到“⋯ → HR 会话关联 · 高级设置”。聊天区仅保留需要处理时的简短入口；设置不会随轮询自动弹出。没有修改绑定数据库或放松后端企业、岗位、招聘者的核验规则。
