# macOS Apple 芯片便携包

本包面向 macOS 11 及以上的 Apple 芯片设备（M1/M2/M3/M4）。包中包含 Python 3.12、PDF 导入、Word 导出和 PDF 导出依赖，因此首次使用不需要安装 Python 或运行 pip。

解压后双击“启动求职搭子.command”。它会优先使用包内 `runtime/bin/python3`，并在浏览器打开本地工作台。终端窗口保持开启即可；按 `Ctrl+C` 停止。

若 macOS 15 及以上提示无法验证开发者，先尝试打开，再到“系统设置 → 隐私与安全性”查看“仍要打开”，按系统提示确认。仅在已核对下载来源和 SHA-256 时使用该例外；若提示“已损坏”或“将损坏电脑”，停止处理，不关闭系统保护。参照 [Apple 官方说明](https://support.apple.com/zh-cn/102445)。当前未完成签名、公证或浏览器下载后的 Gatekeeper 首次打开实测。

数据、API 密钥和扩展配对信息均不在发布包中。首次启动后才会在解压目录的 `data/` 中生成本地资料。升级前复制整个 `data/` 目录，再解压新版到新的目录；用新版的启动脚本加 `--data-dir` 指向旧目录，或在确认后迁移资料。

当前包为 arm64。Intel Mac 需要单独的 x86_64 运行时包，不能在 Rosetta 环境下将本包视为已验收。
