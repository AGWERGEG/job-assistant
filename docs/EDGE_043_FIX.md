# Edge 岗位识别合并修复 0.4.3

合并两种 BOSS 浏览方式：

1. 列表右侧详情：`.job-detail-body > p.desc` + `.more-job-btn` 岗位 ID + 左侧同 ID 卡片。
2. 独立职位页：URL 提供岗位 ID；唯一“职位描述”标题所在卡片内选择正文。页面有两个 `.job-sec-text` 时排除公司介绍等其他模块。

必须在 `edge://extensions` 点击“重新加载”，并刷新所有已打开的 BOSS 标签。侧栏顶部须显示 0.4.3。若还显示 0.4.1/0.4.2，说明 Edge 仍在运行旧目录或旧代码。

合成 DOM 测试 12 项通过，其中 2 项按用户诊断中的真实类名重建。修复后真实 Edge 端到端仍需用户重新加载后确认。
