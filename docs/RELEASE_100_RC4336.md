# RC4.3.36 · 意图与企业信息研究测试版

本版针对 RC4.3.35 的两项验收问题完成修复。

## 意图修复

上下文中先出现 HR 回复、岗位流动性、压力或薪资风险，句末“帮我分析分析”现在保持普通聊天，不创建后台分析任务；独立的“帮我分析分析”仍保留明确建单路径。意图模型和本地守卫同时覆盖，模型误返回 `analyze_job` 时也会降级为 `chat`。

## 企业信息研究

新增 `company_information_request` 意图和受控公开研究模块。用户明确询问企业产品、业务、客户、发展或风评时，可基于当前岗位绑定的公司、已保存公司材料和用户明确允许的公开 HTTPS 来源生成研究预览。来源保留 URL、抓取时间、来源类型和置信度；企业整体资料不会写入用户档案或 JD。只有用户明确确认后，研究摘要才可保存为公司材料。

网络边界：仅 HTTPS、无登录信息、拒绝招聘平台和私网地址、DNS 公网校验、TLS 验证、响应大小和总时限限制；未配置公开搜索供应商时明确提示提供企业官网 URL 或配置搜索，而不假装已完成检索。

## 验证

- Python 意图、对话、公司材料和企业研究测试通过。
- Node 工作台与扩展回归：137 项通过。
- Python 全量回归需在项目规定便携运行时重跑；当前阶段已完成 53 项意图/对话/公司专项测试。

## 限制

本版仍是 v1 RC 测试版，不是正式 v1。企业公开搜索依赖用户明确允许和可用公开来源；不会自动登录招聘网站、读取 Cookie、访问私有员工评价或静默持续监控企业信息。
